DECIMEN — Fountain QR File Transfer

Transfer a file between two devices using only a screen and a camera. Choose what this device should do.

Render

Choose a file and render its fountain-coded QR stream on this screen.

Receiver

Use this device's camera to scan the stream and reconstruct the original file.

The file travels as light. No network path between the two devices is used.

Install Decimen
On iPhone or iPad: tap Share, then “Add to Home Screen”.
